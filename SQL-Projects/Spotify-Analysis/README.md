#  Spotify Playlist & Track Analysis using SQL

##  Project Overview
This project focuses on analyzing Spotify playlist and track data using SQL to extract insights related to user behavior, playlist trends, and track performance. The objective is to explore how users interact with music, playlists, and artists using structured query techniques.

##  Tools & Technologies
- MySQL
- SQL (Structured Query Language)

##  Dataset Description
The dataset includes multiple tables such as:
- Users (username, email, registration date)
- Tracks (track name, artist, album, duration, release date)
- Playlists (playlist name, user association)
- Playlist_Tracks (mapping of tracks to playlists)

##  Key Analysis Performed
### Basic Analysis
- Extracted distinct album and artist information  
- Filtered users based on email domains and registration dates  
- Retrieved track details and calculated average durations  

### Intermediate Analysis
- Playlist-based analysis (track count, duration)  
- User behavior analysis (playlist creation trends)  
- Comparison of track durations with averages  
- Multi-table joins for deeper insights  

### Advanced Analysis
- Subqueries for complex filtering  
- Ranking using window functions  
- Identifying top users and playlists  
- Cross-album and cross-playlist analysis  
- Performance comparison across users and artists  

##  Key Insights
- Identified most active users and playlist creators  
- Analyzed track popularity across multiple playlists  
- Compared playlist sizes and durations  
- Evaluated user engagement based on listening behavior

This project demonstrates advanced SQL skills including joins, subqueries, aggregations, and window functions to analyze real-world music streaming data.
