# Jio-Analysis

##  Project Overview
This project focuses on analyzing employee and department data for Reliance Jio using SQL.
The goal is to extract insights related to employee distribution, department budgets, 
and organizational structure to support HR decision-making.

##  Tools & Technologies
- MySQL
- SQL (Structured Query Language)

##  Dataset Description
The project uses two tables:

1. Employee Table
   - Emp_ID, First_Name, Last_Name, Dept_Code  

2. Department Table
   - Dept_Code, Dept_Name, Dept_Budget  

Both tables are connected using **Dept_Code**.

##  Key Analysis Performed
- Data retrieval using SELECT queries  
- Filtering using WHERE, LIKE conditions  
- Aggregation using COUNT, SUM, AVG  
- Sorting using ORDER BY  
- Join operations between Employee and Department  
- String operations and data formatting  
- Table creation, update, and deletion operations  
- Subqueries and advanced filtering  
- View creation for specific department analysis  

##  Key Insights
- Identified employee distribution across departments  
- Analyzed department budgets and allocation  
- Found highest and lowest budget departments  
- Evaluated employee patterns based on names and departments
