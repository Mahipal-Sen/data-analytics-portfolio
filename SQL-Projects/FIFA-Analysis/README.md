#  FIFA World Cup 2022 Data Analysis using SQL

##  Project Overview
This project focuses on analyzing FIFA World Cup 2022 data using SQL to extract insights related to team performance, match statistics, player usage, and group-level comparisons. The objective is to use SQL queries to uncover trends and evaluate team performance across different metrics.

##  Tools & Technologies
- MySQL
- SQL (Structured Query Language)

##  Dataset Description
The dataset contains information about:
- Team performance (wins, losses, draws, points)  
- Goals scored and conceded  
- Expected goals metrics (xG, xGA, xGD)  
- Player statistics (players used, average age)  
- Match statistics (shots, fouls, possession, passes)  
- Group-level data for tournament analysis  

##  Key Analysis Performed
- Data filtering using WHERE, BETWEEN, LIKE  
- Aggregation using COUNT, SUM, AVG, MAX, MIN  
- Group-based analysis using GROUP BY  
- Sorting using ORDER BY  
- Performance metrics calculation (win %, loss %, draw %)  
- Statistical comparisons across teams and groups  
- Advanced queries for match performance and efficiency  

##  Key Insights
- Identified top-performing teams based on goals and wins  
- Analyzed team efficiency using expected goal metrics  
- Compared team performance across groups  
- Evaluated player usage and team strategies  
- Highlighted strengths and weaknesses of teams
